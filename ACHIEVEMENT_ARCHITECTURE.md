RequiredProgress\n├─ List<RewardDto> Rewards\n└─ IAchievementTrigger Trigger ←─────────────┐\n                                            │\n                    IAchievementTrigger ────┘\n                    ├─ AchievementTriggerType TriggerType\n                    ├─ GetEligiblePlayers(context)\n                    └─ CalculateProgress(context, playerId)\n```\n\n### 触发器的职责划分\n\n```\nIAchievementTrigger\n│\n├─→ GetEligiblePlayers()\n│   │\n│   ├─ 输入：AchievementTriggerContext（包含战斗数据）\n│   │\n│   ├─ 职责：\n│   │  ├─ 检查所有玩家是否满足条件\n│   │  ├─ 过滤出符合成就条件的玩家\n│   │  └─ 返回玩家ID列表\n│   │\n│   └─ 输出：IEnumerable<string> (符合条件的玩家ID)\n│\n│\n└─→ CalculateProgress()\n    │\n    ├─ 输入：AchievementTriggerContext + playerId\n    │\n    ├─ 职责：\n    │  ├─ 计算该玩家的具体进度值\n    │  ├─ 可能需要查询战斗数据获取时间/伤害等\n    │  └─ 返回0到RequiredProgress之间的值\n    │\n    └─ 输出：int (进度值)\n```\n\n### 成就完成流程\n\n```\n战斗结束\n   │\n   ↓\n创建Context\n   │\n   ↓\nCheckBattleEndAchievements()\n   │\n   ├─→ FirstDefense\n   │   ├─ GetEligiblePlayers() → [\"player1\"]\n   │   ├─ CalculateProgress(\"player1\") → 1\n   │   ├─ UpdateAchievementProgress(\"player1\", \"first_defense\", 1)\n   │   └─ If completed → 【成就解锁】\n   │\n   ├─→ PerfectVictory\n   │   ├─ GetEligiblePlayers() → [\"player1\", \"player2\"]\n   │   ├─ CalculateProgress(\"player1\") → 1\n   │   ├─ UpdateAchievementProgress(\"player1\", \"perfect_victory\", 1)\n   │   └─ If completed → 【成就解锁】\n   │\n   ├─→ LongThinking\n   │   ├─ GetEligiblePlayers() → [\"player3\"]\n   │   ├─ CalculateProgress(\"player3\") → 450 (秒)\n   │   ├─ UpdateAchievementProgress(\"player3\", \"long_thinking\", 450)\n   │   └─ If progress >= 600 → 【成就解锁】\n   │\n   └─→ ... (其他成就)\n   \n   ↓\n返回完成的成就列表\n   ↓\n更新玩家奖励\n   ↓\n发送给客户端\n```\n\n### 数据流动示意\n\n```\n          ServerBattle              AchievementTriggerContext\n              │                            ╱\n
