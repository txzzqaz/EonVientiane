## 🎯 游戏概述

**EonVientiane** 是一款支持单机和多人对战的策略性战斗游戏。你将：

✅ **组建装备** - 选择合适的武器、防具和配件  
✅ **参与战斗** - 使用骰子掌握胜负的关键  
✅ **获得成就** - 完成挑战并获得奖励  
✅ **对战玩家** - 与其他玩家进行多人战斗

## 🔐 第一步：登录与角色

### 启动游戏

1. **第一次运行**：游戏将展示欢迎屏幕
2. **登录菜单**：选择以下选项之一：
   - **注册**: 创建新账号
   - **登录**: 使用现有账号登录
   - **单机模式**: 跳过登录，直接开始游戏

### 创建账号

```
1. 选择"注册"
2. 输入用户名（至少3个字符）
3. 设置密码（需包含字母和数字）
4. 确认密码
5. 点击"创建账号"
```

**小提示**：记住你的用户名和密码，以便后续登录！

### 登录账号

```
1. 选择"登录"
2. 输入你的用户名
3. 输入密码
4. 点击"登录"
```

登录成功后，游戏将加载你的存档数据，包括装备、经验和成就。

## 🎁 第二步：了解装备系统

### 打开背包

在主菜单中选择 **"背包"** 或按 **I 键**，你将看到：

#### 👕 装备栏位

| 栏位 | 用途 | 说明 |
|------|------|------|
| 武器 | 提升伤害 | 增加你的攻击力 |
| 防具 | 提升防御 | 减少你受到的伤害 |
| 头部 | 增强属性 | 提升生命值或其他属性 |
| 胸部 | 增强属性 | 增加防御或回避 |
| 脚部 | 增强属性 | 提升速度或移动能力 |
| 手部 | 增强属性 | 提升力量或敏捷 |
| 饰品 | 特殊效果 | 获得特殊能力或加成 |

### 装备道具

1. **浏览物品**：滚动查看你拥有的道具
2. **选择道具**：点击要装备的物品
3. **装备**：点击对应的栏位进行装备
4. **卸下**：再次点击栏位可卸下装备

### 理解属性

每件装备都有以下属性：

| 属性 | 说明 |
|------|------|
| 攻击 (ATK) | 影响你的伤害输出 |
| 防御 (DEF) | 减少你受到的伤害 |
| 生命 (HP) | 你的总血量 |
| 暴击率 | 造成额外伤害的概率 |
| 闪避率 | 躲避敌人攻击的概率 |

**装备建议**：根据你的战斗风格选择不同的装备搭配。

## ⚔️ 第三步：开始战斗

### 进入战斗

1. **返回主菜单**：按 ESC 或选择"返回"

## 🎲 战斗详解

### 战斗界面

```
┌────────────────────────────────────┐
│  敌人：100/100 HP  ████████      │
│  你的队伍：80/100 HP  ██████░░  │
│                                     │
│  回合 #5                          │
│  [攻击] [防御] [特技] [道具]      │
│                                     │
│  战斗日志：                        │
│  > 敌人发起了攻击！               │
│  > 你受到了 25 伤害！             │
└────────────────────────────────────┘
```

### 战斗流程

每一回合有以下阶段：

#### 1️⃣ **选择行动**

选择你要执行的动作：

| 行动 | 效果 | 消耗 |
|------|------|------|
| **攻击** | 对敌人造成伤害 | 无 |
| **防御** | 减少下一回合的伤害 | 无 |
| **特技** | 使用特殊技能造成额外伤害 | 特技值 |
| **道具** | 使用道具回复生命或增加属性 | 物品消耗 |

#### 2️⃣ **掷骰子**

- 双方同时掷骰子确定命中率
- 骰子数值越高，命中概率越大
- 你的 **闪避率** 会提升躲避敌人攻击的概率

#### 3️⃣ **结算伤害**

- 判定双方是否命中
- 计算实际伤害：`(攻击者ATK - 防守者DEF) × 骰子系数`
- 更新双方生命值

#### 4️⃣ **判断胜负**

- 若有一方生命值为0，战斗结束
- 输家失败，赢家获得奖励

### 战斗策略

#### 🛡️ 防守策略
- **当敌人即将发起强力攻击时**：选择防御以减少伤害
- **当你的生命值较低时**：使用防御换取喘息机会

#### 🔪 进攻策略
- **当敌人生命值较低时**：连续发起攻击以快速结束战斗
- **利用骰子**：祈祷掷出高数值以获得更多伤害

#### 🧪 道具策略
- **及时使用恢复道具**：避免生命值降到危险线
- **使用增益道具**：在关键时刻提升属性

## 🎯 成就系统

### 什么是成就？

成就是游戏中的特殊挑战。完成成就可以获得额外的奖励和荣誉。

### 查看成就

1. **主菜单** → 选择 **"成就"**
2. **浏览列表** → 查看所有可用的成就
3. **成就详情** → 点击成就了解完成条件

### 常见成就类型

| 成就 | 条件 |
|------|------|
| 新手胜利 | 赢得第一场战斗 |
| 连胜5局 | 连续赢得5场战斗 |
| 伤害大师 | 单场战斗造成超过200点伤害 |
| 完美防御 | 在一场战斗中格挡超过10次 |
| 装备收集者 | 收集全部装备类型 |

## 👥 多人模式（在线对战）

### 进入大厅

1. **主菜单** → 选择 **"联机对战"**
2. **等待连接** → 游戏连接到服务器
3. **进入大厅** → 查看可用房间或创建新房间

### 创建房间

```
1. 点击"创建房间"
2. 输入房间名称（如："新手房间"）
3. 设置最大玩家数（2-4人）
4. 点击"创建"
5. 等待其他玩家加入
```

### 加入房间

```
1. 浏览可用房间列表
2. 选择感兴趣的房间
3. 点击"加入"
4. 等待房主开始游戏
```

### 房间内操作

| 功能 | 说明 |
|------|------|
| 准备 (Ready) | 告知其他玩家你已准备好 |
| 聊天 (Chat) | 与房间内的玩家交流 |
| 更改装备 | 在战斗开始前更改你的装备 |
| 退出 | 离开房间返回大厅 |

## 💡 新手技巧

### 🎲 掌握骰子
- 骰子结果是随机的，但平均值是固定的
- 多次战斗，你会发现自己的技巧逐渐提升

### 💰 资源管理
- 早期不要过度消费金币
- 留一些金币用于购买更好的装备

### 🛡️ 了解克制关系
- **防御型装备** 克制 **攻击型对手**
- **速度型装备** 克制 **防御型对手**
- **平衡型装备** 适应多种情况

### 📊 查看战斗日志
- 每场战斗后都应该查看战斗日志
- 理解你如何赢或如何输
- 调整下一场战斗的策略

### 🎯 循序渐进
- 先与 AI 对手练习
- 掌握基本规则后再进入多人模式
- 从简单难度开始，逐渐挑战困难

## ❓ 常见问题

### Q: 我该选择哪种装备搭配？
**A:** 根据你的战斗风格选择：
- **进攻型**：优先武器ATK和暴击率
- **防守型**：优先防具DEF和生命值
- **平衡型**：均衡所有属性

### Q: 如何快速获得金币？
**A:** 
1. 多赢战斗获得战斗奖励
2. 完成成就获得奖励
3. 出售不需要的装备

### Q: 为什么我总是输？
**A:** 尝试以下方法：
- 检查你的装备是否合适
- 学习使用防御技能
- 观看战斗日志，理解失败原因
- 从 AI 简单难度开始练习

### Q: 我的数据会丢失吗？
**A:** 
- 单机模式：关闭游戏前确保保存
- 联机模式：数据存储在服务器，不会丢失

### Q: 如何重置我的账号？
**A:** 进入设置，选择"重置账号"（此操作会删除所有数据，请谨慎！）

### Q: 可以与朋友进行私人对战吗？
**A:** 是的！创建一个房间，让朋友加入。房间内只有你邀请的玩家才能加入。

### Q: 游戏支持手机吗？
**A:** 是的，EonVientiane 支持移动设备。在手机上打开游戏，界面会自动适应屏幕大小。
