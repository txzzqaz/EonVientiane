# 多人对战修复测试计划

## 修复内容总结

### 问题1：防守时PD骰子不显示
**原因**：本地玩家在多人战斗初始化时没有装备任何物品，导致当UpdateAvailablePassiveDice尝试查找骰子时找不到任何匹配的骰子。

**修复**：在InitializeMultiplayerBattle中，为本地玩家从当前背包装备物品（SetupPlayerEquipmentFromInventory）。

### 问题2：战斗日志未正确同步
**原因**：GameServer的BroadcastBattleStateAsync没有发送NewBattleLogs，导致客户端收不到战斗日志更新。

**修复**：
1. 在ServerBattle中添加日志索引跟踪（_lastSentLogIndex）
2. 添加GetNewBattleLogs()方法返回自上次发送后的新日志
3. 在GameServer的BroadcastBattleStateAsync中调用GetNewBattleLogs()并添加到通知中

### 问题3：跳过防守功能未验证
**现状**：已经在BattleManager中实现了跳过防守的功能，但需要测试确认它正确发送到服务器。

## 测试步骤

### 前置条件
1. 编译所有项目（Shared, EonVientiane, EonVientianeServer）
2. 启动服务器：`cd EonVientianeServer/bin/Debug/net9.0 && ./EonVientianeServer 7777`
3. 启动两个客户端实例

### 测试流程

#### 测试1：基本多人对战流程
1. 两个客户端都登录/注册账户
2. 第一个客户端创建房间
3. 第二个客户端加入房间
4. 两个客户端都设置为准备状态
5. 游戏自动启动

**预期结果**：进入战斗界面

#### 测试2：PD骰子显示
1. 在战斗中等待第一个玩家进行攻击
2. 第一个玩家选择AD骰子进行攻击
3. **关键：第二个玩家应该进入防守回合**
4. **验证：第二个玩家界面应该显示已装备的PD骰子（如d6）**

**预期结果**：
- 第二个玩家看到防守选项界面
- 能看到"跳过"按钮
- 能看到已装备的PD骰子名称（如"d6骰子"）

#### 测试3：PD骰子选择和跳过
1. 在防守回合中：
   - 尝试点击PD骰子进行防守
   - **或** 点击"跳过"按钮跳过防守
2. **验证**：选择应该正确发送到服务器

**预期结果**：
- 选择防守骰子后，战斗继续进行到下一步
- 点击跳过后，防守方受到伤害，战斗继续

#### 测试4：战斗流程完整性
1. 进行多个回合的完整战斗
2. **验证战斗日志**：应该看到：
   - "第1回合开始"
   - 玩家选择的骰子
   - 攻击信息
   - 防守信息
   - 伤害信息

**预期结果**：
- 日志完整且实时更新
- 没有自动对战现象
- 战斗正确等待玩家输入

#### 测试5：自动电脑行动已修复
1. 在多人战斗中观察
2. **验证**：
   - 不应该看到电脑自动对敌人进行攻击
   - 所有回合都应该等待玩家输入
   - 如果玩家不选择，战斗应该暂停

**预期结果**：战斗完全由玩家驱动，没有自动行动

## 关键验证点

- [ ] 本地玩家在战斗开始时已装备了背包中的物品
- [ ] 防守时能显示PD骰子列表
- [ ] 能正确选择PD骰子或跳过
- [ ] 战斗日志实时同步
- [ ] 没有自动对战现象
- [ ] 跳过按钮功能正常

## 已知限制

目前多人战斗中所有玩家都是真实玩家（没有AI对手）。
